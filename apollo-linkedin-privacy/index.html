Privacy Policy

How Apollo LinkedIn Precision Filter handles profile information, screening history, locally stored records, and user-initiated exports.

Effective October 27, 2026 · Applies to Apollo LinkedIn Precision Filter v2.0.3, offline-license edition

Privacy at a glance

The extension helps users organize and screen accessible LinkedIn profiles using four criteria: recent visible activity, country, connection count, and account join date. This edition stores the screening records locally in Chrome. It does not intentionally transmit saved profile records to an Apollo-operated server and does not include advertising or third-party analytics tracking.

1. Scope

This policy describes the data practices of the Apollo LinkedIn Precision Filter Chrome extension (the “Extension”). It applies to the current locally operating version, not to possible future server-based licensing or cloud services. The Extension is independently developed and is not affiliated with or endorsed by LinkedIn.

2. Information processed

When the user imports profile links or starts a review task, the Extension may process data that is visible and accessible through the user's LinkedIn session, including:

  • Professional profile information: profile names, LinkedIn profile URLs, displayed country or region, connection count, and account join month or year when available.
  • Recent activity evidence: visible posts, comments, reactions and reposts, the time descriptions displayed on those pages, and the time when the Extension checked a page. These signals are not verified login or online-status timestamps.
  • Task and diagnostic data: imported links, screening preferences, task status, processing timestamps, matching outcomes, incomplete fields and error records.
  • Local licensing data: the serial key entered by the user and the locally verified activation status.
  • User-selected files: contents of supported HTML or JSON files explicitly imported by the user, and files the user chooses to export.

The Extension is not designed to collect LinkedIn passwords, private messages, health records, payment card data or precise GPS coordinates.

3. Why the information is used

Data is processed to deliver user-requested features: organizing supplied LinkedIn links, matching accessible profiles against the four screening criteria, recording incomplete or unavailable data accurately, managing and resuming review tasks, verifying a local license, and generating Excel, CSV or backup files at the user's request.

4. Local storage and retention

Version 2.0.3 saves profile records, task information, user preferences and offline activation data using Chrome's extension storage on the user's browser installation. This edition does not automatically upload task databases to Apollo servers or provide remote backups. Records remain until the user clears or replaces them, the Extension is removed, or Chrome data is otherwise deleted. Files already downloaded by the user must be managed and deleted separately.

5. Sharing and third parties

This edition does not intentionally sell collected information or upload locally saved screening results to Apollo-operated servers or advertising providers. Users decide whether to export and share their own reports. LinkedIn pages are loaded by the user's browser and remain subject to LinkedIn's separate practices and policies.

This policy website is published through GitHub Pages. GitHub may process technical website access information according to its own privacy policies; it is not the Extension's profile database.

6. Chrome permissions

  • storage and unlimitedStorage: keep imported links, results, screening settings, task history and license state locally.
  • scripting and linkedin.com host access: analyze information on LinkedIn pages accessible to the user during requested screening tasks.
  • tabs: open and reuse a browser tab for selected profiles and activity pages.
  • sidePanel: show the screening controls and task progress.
  • alarms: support checking and resuming saved tasks after background execution interruptions.

7. Your choices and controls

  • Choose which profile URLs to import and when to begin a task.
  • Change screening settings and pause, stop or restart supported tasks.
  • Export or back up saved records and clear local tasks or records through the Extension's controls.
  • Uninstall the Extension through Chrome's extension management screen. Exports already downloaded remain on your device until you remove them.

8. Security and limitations

The Extension stores data locally using Chrome extension storage; it does not provide an additional end-to-end encryption layer for stored screening records. Users should secure their devices and manage downloaded exports responsibly. Source profile data may be incomplete, outdated or unavailable due to access restrictions.

9. Changes to this policy

We may update this policy when the Extension changes. Before enabling future online serial-key verification, cloud storage or other server functionality, this policy should be revised to explain exactly which additional information is transmitted, where it is stored and how it is used. The effective date will be updated.

10. Contact

For general questions about this Extension or its privacy practices, use the publisher's GitHub issue contact page. Do not post personal or confidential information in public issues. For confidential data requests, use the developer contact information provided in the Extension's Chrome Web Store listing.

The publisher should add a monitored professional privacy-support email here before wider public distribution. No personal email address has been disclosed on this site without confirmation.
